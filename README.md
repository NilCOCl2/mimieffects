# MimiEffects

Аддон к моду [MIMI](https://modrinth.com/mod/mimi) для NeoForge 1.21.1:
превращает живую игру на инструментах в игровые эффекты — от баффов
окружающим игрокам до отпугивания и уничтожения мобов конкретными
мелодиями.

## Идея

Каждой MIDI-песне (или произвольной импровизации) можно назначить:

- **Баффы** игрокам поблизости, зависящие от того, каким составом
  инструментов её играют;
- **Mob purge** — уничтожение враждебных мобов вокруг статичного
  (блочного) инструмента, пока на нём играют конкретную песню. Разные
  песни можно настроить на разные категории целей (например, "Deep Blue"
  на пианино в подводной базе убивает подводных монстров, а "Zemlya" на
  том же пианино дома — наземных и летающих).

Все правила живут в JSON-файлах (`config/mimieffects/tracks/*.json`) и
редактируются либо руками, либо через встроенный в игру редактор.

## Реализовано

- **Точка входа мода**, серверный конфиг (`GlobalConfig`) с рабочим
  конфиг-экраном NeoForge (кнопка "Config" в списке модов; на реальном
  сервере поля доступны только локальному хосту — ограничение самого
  NeoForge, не этого мода).
- **`/mimieffects reload`** — перечитывает
  `config/mimieffects/tracks/*.json` и одновременно сканирует
  `config/mimi/server_midi_files/` на предмет MIDI-файлов без конфига,
  создавая для них пустые заготовки (`TrackScaffolder`) с правильным,
  реально вычисленным MIMI `track_id` (UUID, а не имя файла — см.
  `REVERSE_ENGINEERING.md`).
- **`/mimieffects gui`** — открывает встроенный в игру редактор треков:
  список файлов слева, справа редактирование инструментов/эффектов/
  mob_purge выбранного трека. ID инструментов и эффектов выбираются из
  реального списка (тот же реестр, что видит автодополнение команд), а
  не вводятся текстом.
- **Живое применение эффектов и mob purge** — через NeoForge Mixin в
  `ServerNoteConsumerManager.handleEvent` (реальный публичный API-пакет
  MIMI `common.api.event`), конвертирующий каждую сыгранную ноту в
  проверку "какой трек сейчас играет этот инструмент" и применение
  соответствующих эффектов/purge.
- **Защита боссов** (`GlobalConfig` → `[Protection]`) — глобальный
  список типов/тегов сущностей, которые никогда не затрагиваются ни
  баффами, ни mob purge, независимо от настроек конкретного трека. По
  умолчанию исключены `minecraft:ender_dragon` и `minecraft:wither`.
- Локализация (en_us/ru_ru) для конфиг-экрана и сообщений команд.

## Известные ограничения

- **Сопоставление трека происходит по одной ноте от одного инструмента
  за раз**, а не по-настоящему собранному ансамблю нескольких игроков.
  Это значит: аранжировки, требующие **нескольких разных** инструментов
  одновременно (например, "Full Band" в `zemlya.json`), сейчас
  никогда не совпадают — реально работают только аранжировки с ровно
  одним требуемым инструментом ("Solo" и подобные).
- Один набор `targets` (кому идёт эффект: игроки/враждебные/нейтральные/
  дружелюбные) на всю аранжировку — нельзя внутри одной аранжировки
  задать разным эффектам разные цели (например, "лечить союзников, но
  вредить враждебным" одним списком эффектов).
- В редакторе можно менять только первую аранжировку трека; у треков с
  несколькими аранжировками остальные сохраняются, но не редактируются
  из GUI.
- До 5 слотов инструментов и 5 слотов эффектов на аранжировку в
  редакторе (для большего — редактировать JSON руками).
- Нет предмета "дирижёрская палочка" и связанного отдельного UI —
  редактор открывается только командой.

## Как собрать

```
gradlew.bat build
```

(Linux/macOS: `./gradlew build`). Требуется JDK 21. Первая сборка
качает NeoForge toolchain и зависимость на MIMI из Modrinth Maven — это
нормально, несколько минут на первый раз.

Готовый джар: `build/libs/mimieffects-<версия>.jar`. Кладём рядом с
джаром **MIMI** соответствующей версии в `mods/`.

## Структура конфига трека (кратко)

```jsonc
{
  "track_id": "<UUID, вычисляется автоматически — не трогать руками>",
  "display_name": "Имя для отображения",
  "arrangements": [
    {
      "name": "Solo",
      "required_instruments": { "mimi:acguitar": 1 },
      "effects": [
        { "effect": "minecraft:regeneration", "base_level": 1, "max_level": 3 }
      ],
      "affects": "all_nearby"
    }
  ],
  "mob_purge": {
    "radius_blocks": 128,
    "requires_static_instrument": true,
    "environment": "surface",
    "hostile_only": true,
    "purge_interval_ticks": 20
  }
}
```

Полное описание того, как устроен MIMI изнутри (используемые публичные
API, формат `track_id`, реестр инструментов) — в `REVERSE_ENGINEERING.md`.
