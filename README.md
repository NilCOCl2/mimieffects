# MIMI Effects

Аддон к [MIMI](https://modrinth.com/mod/mimi) для NeoForge 1.21.1. Идея
простая: MIMI умеет играть настоящую живую музыку в майнкрафте — этот мод
даёт этой музыке смысл. Каждой песне можно назначить, что она делает с
миром вокруг: лечит и усиливает игроков, изгоняет и убивает мобов,
требует конкретных инструментов и конкретное число музыкантов. Всё это
настраивается без исходников — через JSON-файлы или встроенный в игру
редактор.

## Как это работает

Когда кто-то играет на инструменте MIMI (не важно, портативном или
стационарном), мод смотрит:

1. **Какая песня сейчас звучит** — по `track_id`, который MIMI сам
   вычисляет из MIDI-файла (это не имя файла, а хэш; трогать руками не
   нужно и почти невозможно).
2. **Кто рядом и на чём играет** — все, кто в данный момент играет
   *ту же самую* песню в радиусе `base_radius`, объединяются в один
   "ансамбль" (кластер). Игроки, играющие разные песни рядом друг с
   другом, друг другу не мешают, если явно не включена реакция на
   диссонанс.
3. **Подходит ли инструментальный состав ансамбля** под одну из
   аранжировок этого трека (`required_instruments`) — только тогда
   применяются эффекты.

### Баффы ансамблю

Эффект каждой аранжировки масштабируется двумя независимыми бонусами:
за число игроков в ансамбле (`per_player_bonus`) и за полноту набора
инструментов (`full_ensemble_bonus`). Соло-игра работает и даёт базовый
эффект — полный состав делает его сильнее, а не включает с нуля (если
только вы явно не поставили трек на "только полным составом", см. ниже).

- **Играть можно и соло** — это по умолчанию. Хотите трек, который
  вообще не работает меньше чем полным составом — поставьте
  `min_ensemble_size` на аранжировке (жёсткий порог по головам,
  независимо от того, какие инструменты набрались).
- **Один трек — несколько слоёв эффектов**: у каждого эффекта в
  аранжировке свой `min_ensemble_size` — например, "Удача" всегда
  активна соло, а "Везение II" подключается только когда собралось
  трое и больше. Один и тот же трек может постепенно "раскрываться" с
  ростом состава.
- **Диссонанс**: если рядом одновременно играют разную музыку,
  поведение настраивается (`Ensemble.behavior` в конфиге) — понизить
  уровень эффекта (`reduce`), не давать эффект вовсе (`cancel`) или
  игнорировать чужую музыку (`ignore`).
- **Замедление во время игры**: пока держите переносной инструмент в
  руках и реально играете ноты — небольшое замедление (Slowness II на
  несколько секунд, обновляется на каждой ноте). Стационарные
  (блочные) инструменты и так обездвиживают игрока штатной механикой
  MIMI (посадка на сиденье), так что для них ничего добавлять не
  пришлось.

### Изгнание мобов (`mob_purge`)

Отдельная, необязательная механика на уровне трека (не аранжировки):
пока играется конкретная песня на **стационарном** инструменте (по
умолчанию — можно разрешить и на переносном), музыка постепенно
наносит урон подходящим мобам в радиусе и заставляет их в панике
убегать, пока трек не доиграет или моб не погибнет. Никаких мгновенных
убийств одной нотой — только постепенное затухание.

Настраивается тонко: только враждебные или вообще все, только на
поверхности/только под водой/везде, свой урон за тик и интервал
между "ударами", радиус, который растёт с числом музыкантов в
ансамбле (опционально, чтобы не превращать это в бесконтрольный
AoE-инструмент). Боссы (по HP-порогу, точному ID, тегу или целому моду)
защищены от изгнания глобально — если специально не разрешить обратное
в конфиге сервера.

При изгнании подавляется дроп опыта (чтобы это не превращалось в
фарм) и выпадают только "стоящие" предметы — броня, оружие, инструменты
и что угодно с рарностью выше обычной (зачарованное или помеченное как
редкое любым другим модом); кости, тухлая плоть и подобный мусор не
засоряют мир лишними сущностями.

### Нотные свитки

Чтобы получить баффы от трека, недостаточно просто сыграть его —
нужно ещё держать в инвентаре (не в руке, просто где угодно в
инвентаре) **нотный свиток**, привязанный именно к этому треку. Это
не расходуемый предмет — один свиток работает бесконечно, пока лежит
в инвентаре. Свиток **не** ограничивает `mob_purge` — изгнание мобов
работает независимо от того, есть свиток или нет.

- Крафта нет и не будет — специально, чтобы мод можно было спокойно
  снять с сервера в любой момент без последствий для процесса
  крафта или прогрессии.
- Получить свиток можно у деревенского NPC-музыканта из самого MIMI
  (профессия "инструменталист", уже с первого уровня торговли) либо
  через креатив/`/give`.
- В творческом инвентаре, во вкладке "Ингредиенты", лежит по одному
  привязанному свитку на каждый загруженный трек — как зачарованные
  книги по одной на чары, а не один бесполезный непривязанный стак.
- Тултип свитка (при зажатом Shift) показывает, какие именно
  инструменты нужны и сколько игроков требуется для каждого эффекта —
  подбирать состав вслепую не нужно.

## Редактор треков и генератор

`/mimieffects gui` открывает встроенный в игру редактор: слева список
файлов треков, справа — название, привязанные инструменты, эффекты,
цели (кому давать эффект), настройки изгнания мобов и порог ансамбля.
Инструменты и эффекты выбираются из реального списка, который видит
сам MIMI и реестр эффектов сервера — не текстом наугад.

Если руками настраивать десятки треков лень, **`/mimieffects
genscrolls`** сам заполнит все ещё не тронутые заготовки: подберёт
1-3 честных ванильных положительных эффекта (иногда — осмысленной
парой вроде "дыхание глубин + дельфинья грация"), нужные под них
инструменты (с приоритетом на ходовые — духовые, гитары, микрофоны,
пианино, барабаны — конфигурируется), и в редких случаях добавит
одному треку на весь набор изгнание мобов пополам с лечебными
эффектами. Уже настроенные вручную треки генератор не трогает.
`/mimieffects clearscrolls confirm` сбрасывает всё обратно в чистые
заготовки, если нужно перегенерировать по новой.

## Команды

Все команды требуют уровень оператора 2+.

| Команда | Что делает |
|---|---|
| `/mimieffects reload` | Перечитать `config/mimieffects/tracks/*.json`, создать заготовки для новых MIDI-файлов без конфига |
| `/mimieffects gui` | Открыть редактор треков |
| `/mimieffects genscrolls [макс. размер ансамбля]` | Автозаполнить незаполненные треки случайными эффектами/инструментами |
| `/mimieffects clearscrolls confirm` | Сбросить все треки обратно в незаполненное состояние |

## Конфиг сервера

`config/mimieffects-server.toml`, синхронизируется клиентам при входе.
Секции: **General** (радиус ансамбля, интервал тика, таймаут сессии,
поведение по умолчанию, лимиты редактора), **Ensemble** (бонусы за
игроков/полноту состава, поведение при диссонансе), **MobRules**
(защита боссов, доп. правила враждебности), **Generation** (приоритет
инструментов при генерации), **Debug** (пошаговая трассировка каждой
ноты — включайте, когда что-то "просто не работает", вместо того
чтобы гадать).

## Пример конфига трека

```jsonc
{
  "track_id": "<UUID, вычисляется MIMI автоматически — не трогать руками>",
  "display_name": "Название трека",
  "spell_name": "Гимн изгнания: Прыткость",
  "artist": "Исполнитель (необязательно)",
  "midi_file_name": "song.mid",
  "arrangements": [
    {
      "name": "Соло",
      "required_instruments": { "mimi:acguitar": 1 },
      "effects": [
        { "effect": "minecraft:regeneration", "base_level": 1, "max_level": 3, "min_ensemble_size": 1 },
        { "effect": "minecraft:absorption", "base_level": 1, "max_level": 2, "min_ensemble_size": 2 }
      ],
      "affects": "all_nearby",
      "min_ensemble_size": null
    }
  ],
  "mob_purge": {
    "radius_blocks": 64,
    "max_radius_blocks": null,
    "requires_static_instrument": true,
    "environment": "surface",
    "hostile_only": true,
    "purge_interval_ticks": 20,
    "damage_per_tick": 4.0
  }
}
```

## Известные ограничения

- В редакторе можно менять только первую аранжировку трека — у треков
  с несколькими вариантами (соло/дуэт/полный состав) остальные
  сохраняются на диске, но не редактируются из GUI.
- Один набор целей (`targets`) на всю аранжировку — нельзя одним
  списком эффектов одновременно "лечить союзников и вредить
  враждебным" с разными целями на разные эффекты.
- Отдельного предмета-"открывашки" редактора нет — только команда.
- На реальном (не одиночном) сервере экран конфига мода доступен
  только локальному хосту — это ограничение самого NeoForge, не мода.

## Сборка

```bash
./gradlew build
```

(Windows: `gradlew.bat build`.) Нужен JDK 21. Первая сборка качает
NeoForge toolchain и зависимость на MIMI из Modrinth Maven — несколько
минут, это нормально.

Готовый джар — `build/libs/mimieffects-<версия>.jar`. Кладите рядом с
джаром **MIMI** нужной версии в `mods/`.
